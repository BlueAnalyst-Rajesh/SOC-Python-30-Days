# SOC Python 30-Day Challenge

A 30-day hands-on learning journey focused on using Python for Security Operations Center (SOC) tasks.

## 🎯 Objective

The goal of this challenge is to develop practical Python skills for cybersecurity and SOC operations.

Throughout this challenge, I will practice:

- Security log analysis
- Log parsing
- IOC extraction
- Authentication log analysis
- Regex
- CSV and JSON processing
- Security automation
- Threat intelligence API integration
- Suspicious activity detection

## 🗂️ Challenge Structure

| Phase | Days | Focus |
|---|---:|---|
| Phase 1 | 1–5 | Python Fundamentals for SOC |
| Phase 2 | 6–10 | Regex & IOC Extraction |
| Phase 3 | 11–15 | CSV, JSON & Log Parsing |
| Phase 4 | 16–21 | SOC Automation |
| Phase 5 | 22–25 | APIs & Threat Intelligence |
| Phase 6 | 26–30 | Final SOC Automation Project |
